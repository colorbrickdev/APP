애터미 쇼핑몰 프로토타입 개선 보고서

대상 기간: 2026. 7. 9.(수) ~ 7. 10.(금) · 대상: 통합 프리뷰 및 기기별 배포 화면(PC · Fold7 · S26 Ultra · iPhone17)

요약 — 이틀간 총 8개 영역을 개선했습니다. 회원·주문 체계(3초 간편가입, 주문내역, 사업자 가입 연계)를 신설하고, AI 맞춤 진열·통합 검색을 고도화했으며, 신규 기능 전반에 다국어(한/영/일/중)를 적용했습니다. 영상 소리 잔류·닫기 버튼 겹침 등 품질 이슈를 수정하고 배포 패키지를 2회 내보냈습니다.

01회원 · 주문 체계 신설

  • 3초 간편가입 — 휴대폰 번호 인증 + 최초 1회 비밀번호 설정 후, 이후에는 번호+비밀번호 조합으로 로그인. 번호 입력 시 하이픈(-) 자동 포맷.
  • 주문내역 — 상단 아이콘을 '주문내역' 텍스트 라벨로 직관화. 간편회원은 주문 목록 자동 연결, 비회원은 주문번호+휴대폰 번호로 조회. 연동 해제(로그아웃) 버튼 시인성 개선.
  • 주문 완료 연계 — 주문 완료 시 간편가입 유도 카드 노출, 가입 시 해당 주문 자동 연결.
  • 사업자 가입 연계 — 주문내역 내 '애터미 사업자 가입' 카드에서 간편회원 정보(이름·번호·주소) 인계 동의 후 공식 가입 페이지(atomy.page)로 이동. 인생시나리오의 '애터미 사업자 되기' 버튼에도 동일 링크 연결.
  • 회원 전용 알림 — 구매 10회 달성 등 계정 기반 알림을 간편연동 회원에게만 노출하도록 정리.

02AI 맞춤 진열 고도화

  • 질문 재설계 — ① 누구를 위한 제품인지 ② 신경 쓰는 부분 ③ 예산, 3문항 구성.
  • CTA 개선 — '진열장을 준비할게요' 문구로 변경, 히어로 하단 배치, 시안색 펄스 링 + 중앙 정렬 그림자로 시인성 강화.
  • 맞춤 상태 관리 — 맞춤 진열 중 상태 칩 + '맞춤 해제' 버튼 제공, 맞춤 시 무관한 카테고리 행 정리.

03통합 검색

  • 검색 오버레이 — 모바일·데스크톱 공통. 인기 검색어 칩, 실시간 제품 결과(클릭 시 상세 이동), 석세스클립 결과 연결.
  • 데스크톱 최적화 — 검색 필드 바로 아래에 적정 너비 드롭다운으로 표시되도록 조정.

04석세스클립

  • 정렬 필터 — 추천순 / 최신순 / 조회수순 / 좋아요순 추가 (모바일·데스크톱).
  • 채널 필터 정정 — 전체 / 공식 / 개인으로 수정.
  • 플레이어 수정 — 닫기 버튼이 이동 화살표에 가려지던 겹침 오류 수정(레이어 순서 조정 + 화살표 위치 분리).

05제품 구매 · 상세

  • 브레드크럼 내비게이션 — 홈 > 카테고리 > 제품 각 단계 클릭 시 해당 페이지로 이동, 전 상품 상세에 노출.
  • 기기 간 오류 수정 — iPhone17에서 장바구니 담기 시 S26 Ultra 화면에 반영되던 교차 오류 해결.

06인생시나리오

  • 수레바퀴 차트 확대 — S26 Ultra·iPhone17에서 좌우 정비례 확대.
  • 조작감 개선 — 8개 항목 클릭 시 화면이 아래로 스크롤되던 현상 제거.

07다국어(한 · 영 · 일 · 중) 적용

  • 신규 기능 전체 — 간편가입·로그인·주문내역·사업자 가입·AI 맞춤 진열(질문/선택지/칩/토스트)·쇼핑 브리핑·정렬 필터·검색 UI.
  • 사회적 증명 토스트 — 5종(구매 10회·배송 출고·신규 혜택·새 콘텐츠·리뷰 적립) 눈썹·제목·본문 번역, 표시 시점 언어 자동 반영.

08품질 점검 · 배포

  • 영상 소리 잔류 수정 — 클립 재생 중 페이지 이동 시 플레이어·영상 모달 자동 종료 + 재생 중 미디어 일시정지 안전망 적용(모바일·데스크톱).
  • 배포 패키지 — 다국어 반영본 및 최종본 zip 2회 내보내기. 기기별 직접 접속 라우트(/pc · /fold · /s26 · /iphone) 포함.
